Academic paper / conference

IEEE/Elsevier style. Tight column widths, vector PDF figures, LaTeX tables, compact captions.

B

Master's / PhD thesis

More space, explanatory captions, can include more detail per figure.

Technical report / internal

HTML/Markdown/Word. Flexible layout, raster PNG fine, tables in Markdown.
